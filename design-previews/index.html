Design Previews

Abrí cada opción y comparalas con la tool real. Cada archivo es standalone — no necesitan servidor.

A · Playnite-like

Elegante · data-heavy · profesional
Azul profundo + acentos cyan + dorado sutil. Tipografía Inter. Cards con bordes finos y sombras difusas. Vibe de app profesional tipo Linear o JetBrains.

B · Steam Deck OS

Gaming oficial · verde neón · negros profundos
Negros hasta #000, verde ácido como color de acción, azul SteamUI secundario. Bordes marcados, badges con glow. Inspirado en SteamOS 3.

C · Cyberpunk / Synthwave

Agresivo · alto contraste · nocturno
Magenta + cyan neón sobre negros azulados. Glows fuertes, tipografía Orbitron. Impacto visual pero cansa en sesiones largas.

D · Heroic / Moderno

Suave · confortable · ideal para uso largo
Gris-azul medio tipo Discord / Obsidian / Raycast. Violetas + cyan cálido. El más usable para sesiones largas. Mi voto personal.
